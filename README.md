# dream-market-app

A simple web prototype for recording dreams, extracting keywords using GPT, and visualizing their market value.

## ✅ Requirements

This project requires the following Python packages:

flask==3.0.3  
openai==1.44.0  
httpx==0.27.2  
python-dateutil==2.9.0.post0  

- Compatible with Python 3.9 and above (zoneinfo is built-in)
- You may add `pandas` for CSV or structured data processing



## ✅ Environment Variables

OPENAI_API_KEY → your OpenAI API key  
(optional) PYTHON_VERSION → 3.11
