This project requires the following Python packages:

flask==3.0.3
openai==1.44.0
httpx==0.27.2
python-dateutil==2.9.0.post0

- Compatible with Python 3.9 and above (no need to install zoneinfo separately).
- If you plan to handle CSV or structured data, consider adding pandas.

--------------------------------------------

✅ Environment Variables (in Render dashboard)

OPENAI_API_KEY → your OpenAI API key  
(optional) PYTHON_VERSION → 3.11  

Render uses the latest stable Python by default, but you can specify a version.
